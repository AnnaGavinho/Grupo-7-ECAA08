Lógica de Predicados, Quantificadores e Varredura Global de Sensores

Módulo de varredura global (SCADA State Scanning Engine) com lógica de primeira ordem.

1. Fundamentos: Lógica de Predicados e Quantificadores

Nas Aulas 02 a 05, as condições de segurança foram tratadas via Lógica Proposicional, com cada sinal discretizado em uma variável booleana fixa. Porém, uma planta com dezenas de instrumentos torna o software supervisório rígido se cada sensor for tratado individualmente. Para superar essa limitação, emprega-se a Lógica de Primeira Ordem (LPO).

  • Universo de discurso $\mathcal{U}$: conjunto de todos os elementos sob supervisão (instrumentos, setores, atuadores, motores).
  • Predicado $P(x)$: função proposicional parametrizada que mapeia um elemento $x \in \mathcal{U}$ em um valor-verdade.

1.1. Quantificador Universal (∀)

$$\forall x \in \mathcal{U}, P(x) \iff P(i_1) \land P(i_2) \land \dots \land P(i_n)$$

Basta um único contraexemplo $P(k) = \text{Falso}$ para invalidar toda a proposição (curto-circuito de falsidade).

1.2. Quantificador Existencial (∃)

$$\exists x \in \mathcal{U}, Q(x) \iff Q(i_1) \lor Q(i_2) \lor \dots \lor Q(i_n)$$

Basta uma única testemunha $Q(k) = \text{Verdadeiro}$ para validar a proposição (curto-circuito de veracidade).

1.3. Quantificação sobre Subdomínios Restritos

Frequentemente quantifica-se apenas sobre uma classe restrita de instrumentos (ex.: só termômetros do Forno de Torra).

$$\forall x \in \mathcal{S}, P(x) \iff \forall x\,(\text{PertenceAoSetor}(x,\mathcal{S}) \rightarrow P(x))$$

$$\exists x \in \mathcal{S}, Q(x) \iff \exists x\,(\text{PertenceAoSetor}(x,\mathcal{S}) \land Q(x))$$

⚠️ Importante

A implicação ($\rightarrow$) no universal garante que elementos fora do subconjunto não falseiem a avaliação por vacuidade ($F \rightarrow P(x) \equiv V$). No existencial, a conjunção ($\land$) garante que a testemunha pertença de fato ao subdomínio.

1.4. De Morgan para Quantificadores

$$\neg(\forall x\, P(x)) \equiv \exists x\,(\neg P(x)) \qquad \neg(\exists x\, Q(x)) \equiv \forall x\,(\neg Q(x))$$

"Não é verdade que todos os instrumentos estão calibrados" ⟺ "Existe ao menos um instrumento descalibrado".

Equações Lógicas Globais de Supervisão

Prontidão Geral da Planta:

$$\text{PlantReadiness} \iff (\forall x \in \mathcal{I}, \text{IsSaudavel}(x)) \land (\neg \exists e \in \mathcal{E}, \text{IsEmergenciaAtiva}(e))$$

Intertrava Crítica de Segurança Alimentar:

$$\text{QualityTrip} \iff (\exists d \in \mathcal{D}_{met}, \text{IsMetalDetectado}(d)) \lor (\exists v \in \mathcal{V}_{vis}, \text{IsDefeitoOptico}(v))$$

Alívio Térmico do Forno:

$$\text{ThermalTrip}_{\text{Forno}} \iff \exists t \in \mathcal{T}_{\text{Forno}}, \text{IsSobretemperatura}(t)$$

Permissivo de Rota e Embalagem:

$$\text{Perm}_{\text{Embalagem}} \iff (\forall p \in \mathcal{P}_{\text{Pneum}}, \text{IsPressaoArOK}(p)) \land (\exists m \in \mathcal{M}_{\text{Esteiras}}, \text{IsMotorLigado}(m))$$

4. Notebook: Motor de Quantificação

def forall(dominio, predicado):
    contraexemplos = [x for x in dominio if not predicado(x)]
    return (len(contraexemplos) == 0, contraexemplos)

def exists(dominio, predicado):
    testemunhas = [x for x in dominio if predicado(x)]
    return (len(testemunhas) > 0, testemunhas)

def forall_in(dominio, guarda, predicado):
    return forall([x for x in dominio if guarda(x)], predicado)

def exists_in(dominio, guarda, predicado):
    return exists([x for x in dominio if guarda(x)], predicado)

class SCADAScanningEngine:
    def __init__(self, instrumentos):
        self.instrumentos = instrumentos

    def executar_varredura(self):
        univ_saudavel, falhas = forall(self.instrumentos, is_saudavel)
        emergencia, _ = exists_in(self.instrumentos,
            lambda i: i.tipo == TipoInstrumento.EMERGENCIA, is_emergencia_ativa)
        plant_readiness = univ_saudavel and not emergencia

        metal, _ = exists_in(self.instrumentos,
            lambda i: i.tipo == TipoInstrumento.DETECTOR_METAL, is_metal_detectado)
        defeito, _ = exists_in(self.instrumentos,
            lambda i: i.tipo == TipoInstrumento.CAMERA_VISAO, is_defeito_optico)
        quality_trip = metal or defeito

        thermal_trip, _ = exists_in(self.instrumentos,
            lambda i: i.setor == Setor.SETOR_200, is_sobretemperatura)

        return {
            "PlantReadiness_OK": plant_readiness,
            "QualityTrip_Ativo": quality_trip,
            "ThermalTrip_Forno_Ativo": thermal_trip,
        }

Em cenários de teste, o motor detectou corretamente contaminação por metal (Cenário A) e sobreaquecimento do forno com $TT{-}201 = 175^\circ\text{C} > 160^\circ\text{C}$ (Cenário B), disparando os respectivos trips.
