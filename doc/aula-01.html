3. Classe Base TagSCADA

Todo instrumento da planta (sensor ou atuador) é representado como uma instância de uma classe comum, que guarda o valor bruto do sinal (analógico ou digital), o tag ISA-5.1, o setor a que pertence e a função de discretização (contínuo → proposição booleana) usada na Aula 02: 

class TagSCADA:
    def __init__(self, tag, setor, tipo, valor_bruto=0.0, limite_critico=None):
        self.tag = tag                    # Ex: "TT-201"
        self.setor = setor                # Ex: "Setor 200 - Torra"
        self.tipo = tipo                  # analogico | digital
        self.valor_bruto = valor_bruto    # sinal 4-20 mA ou estado 0/1
        self.limite_critico = limite_critico

    def proposicao(self):
        # Converte o sinal bruto em uma proposicao booleana (Aula 02)
        if self.tipo == "digital":
            return bool(self.valor_bruto)
        return self.valor_bruto >= self.limite_critico
