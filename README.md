# Projeto SCADA — Linha de Produção de Paçoca

## Visão Geral
O objetivo deste projeto é projetar a arquitetura completa de automação e supervisão de uma linha de produção agroindustrial. O processo abrange desde o recebimento do amendoim no campo até a expedição do produto final embalado.

A planta opera sob rigorosos padrões de controle de qualidade e rastreabilidade, integrando controle discreto, malhas analógicas contínuas (PID) e sistemas de visão computacional.
